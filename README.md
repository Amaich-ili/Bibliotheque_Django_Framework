
# Site pour une Bibliothèque dans un environnement Framework Django.
## Description:
* LE site a pour but de faciliter la recherche d'un livre par catégorie pour l'utilisateur.
* Faciliter l'enregistrement de l'utilisateur, s'il n’existe pas dans la base de données.
* Un jeu de cartes est proposé, ayant des images de livres, pour rendre l'accès à ce site plus agréable.
## Installation:
Nous avons utilisé pour notre site, Django qui est un Framework Python de haut niveau; 
qui permet un développement rapide de sites internet, sécurisés, et maintenables.

## Utilisation:
* Quand l'utilisateur se connecte, s'il est inscrit, l'accès se fait via la page login,
  mais s'il n'existe pas, l'utilisateur pourra créer un compte qui l'enregistre dans la 
  Base de données de la bibliothèque. 
*  L’utilisateur peut effectuer des recherches pour connaitre la disponibilité des livres.
* Lors de la recherche, les livres seront affichés par catégorie, ce qui va faciliter l'accès.
* En dernier un jeu de cartes est proposé, deux rangés de huit cartes, ayant comme face, l'image 
  de livre de différente catégories, mais caché a l'utilisateur.
* L'utilisateur devras choisir une carte, et après une autre carte, si la carte est similaire, 
  il continue à jouer et essaye de trouver deux autre carte semblable,
  si les carte ne sont pas semblable, il choisit une autre, j'usqu'a finir toute les cartes.
* Un message sera affiché, si l'utilisateur gagne.
